# Design

## Project Title
Implement Client Script & UI Policy (Incident)

## System Design

The system is designed to automate and control the Incident form in ServiceNow using Client Script and UI Policy.

## Workflow

Open Incident Form
↓
Enter Incident Details
↓
Client Script Executes
↓
UI Policy Executes
↓
Fields are Updated
↓
Save Incident
↓
Verify the Result

## Client Script

Client Script is used to perform client-side actions on the Incident form based on user input or form events.

## UI Policy

UI Policy is used to control the form fields by making them visible, hidden, mandatory, or read-only based on defined conditions.

## Expected Result

The Incident form should automatically apply the configured Client Script and UI Policy rules and display the expected field behavior.
