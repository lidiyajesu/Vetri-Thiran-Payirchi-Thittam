# Documentation

## Project Title

Implement Client Script & UI Policy (Incident)

## Project Overview

This project demonstrates the implementation of a Client Script and UI Policy in ServiceNow to improve the behaviour and control of the Incident form.

## Features

### Client Script
- Prevents Incident State changes through list editing.
- Displays an alert message when an invalid list edit is attempted.

### UI Policy
- Applies conditions based on Incident Impact.
- Controls the configured Incident fields.
- Helps maintain consistent form behaviour.

## Technologies Used

- ServiceNow
- Client Script
- UI Policy
- JavaScript
- Incident Management

## Project Workflow

User → Incident Form → Client Script / UI Policy → Field Validation & Control → Updated Incident
